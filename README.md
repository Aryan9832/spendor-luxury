# Spendor Audio - Luxury Website Clone

A high-end, luxury redesign of the Spendor Audio website featuring elegant design, smooth animations, and a premium user experience.

## 🎵 Features

- **Luxury Design**: Elegant color palette with gold accents, sophisticated typography, and premium aesthetics
- **Smooth Animations**: Scroll-triggered animations, parallax effects, and smooth transitions
- **Fully Responsive**: Beautiful on all devices from mobile to desktop
- **Interactive Elements**: Hover effects, custom cursor, form validation
- **Performance Optimized**: Lazy loading, debounced scroll handlers, optimized animations

## 🎨 Design Elements

- **Color Scheme**: 
  - Primary Gold: #D4AF37
  - Deep Navy: #0A1628
  - Charcoal: #1C1C1E
  - Off-White: #F8F7F4

- **Typography**:
  - Headings: Cormorant Garamond (Serif)
  - Body: Montserrat (Sans-serif)

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. No build process required - pure HTML, CSS, and JavaScript
3. All external resources (fonts, images) are loaded from CDN/original sources

## 📱 Responsive Breakpoints

- Desktop: 1200px and above
- Tablet: 992px - 1199px
- Mobile: Below 992px

## 🔧 Customization

To customize the website:

1. **Colors**: Edit CSS variables in `:root` section of `styles.css`
2. **Fonts**: Change Google Fonts imports in `index.html` header
3. **Content**: Update text directly in `index.html`
4. **Images**: Replace image URLs in both HTML and CSS
